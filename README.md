# AI_Manufacturing_Quality_Analytics

An end-to-end Machine Learning project that predicts manufacturing quality by applying data preprocessing, feature engineering, dimensionality reduction, clustering, and multiple supervised learning algorithms.

This project demonstrates a complete industry-style ML workflow from raw data analysis to trained model serialization.

---

# 🚀 Project Highlights

✔ Exploratory Data Analysis (EDA)

✔ Data Cleaning

✔ Missing Value Handling

✔ Feature Engineering

✔ Label Encoding & One-Hot Encoding

✔ Feature Scaling

✔ Principal Component Analysis (PCA)

✔ K-Means Clustering

✔ Machine Learning Pipelines

✔ Model Comparison

✔ Performance Evaluation

✔ Model Serialization using Joblib
